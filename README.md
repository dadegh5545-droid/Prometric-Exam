# مِجهر — Prometric MLT (Qatar)

تطبيق تحضير لامتحان **Prometric / QCHP** لفنّي وأخصّائي المختبرات الطبية في قطر.
صفحة HTML واحدة تعمل بلا خادم وبلا اتصال بعد أول تحميل، وتحفظ تقدّمك في المتصفّح.

## المحتوى

**1120 سؤال اختيار من متعدد**، لكلٍّ منها شرحٌ إنجليزي للإجابة وسطرٌ عربي مختصر:

| القسم | العدد | | القسم | العدد |
|---|---:|---|---|---:|
| الكيمياء السريرية | 215 | | الجودة والسلامة والسحب | 113 |
| أمراض الدم | 185 | | المناعة والمصليات | 95 |
| الأحياء الدقيقة | 161 | | البول وسوائل الجسم | 66 |
| بنك الدم | 121 | | الأنسجة والخلايا | 65 |
| الطفيليات | 57 | | الفطريات والفيروسات | 42 |

يشمل البنك أسئلة سيناريو سريري، وأسئلة حسابية، وأسئلة نفي (EXCEPT)،
والوراثة الخلوية والجزيئية، ومسح حديثي الولادة.

## الأوضاع

- **تدريب** — بالقسم أو مختلط، تصحيحٌ فوري مع الشرح، مع خيار حصر الجلسة في الأسئلة الجديدة أو الأخطاء أو المستحقّة للمراجعة.
- **امتحان محاكٍ** — 50/100/150 سؤالًا بنسب البنك، بمؤقّت، بلا تصحيح فوري، ثم نتيجة بالأقسام ومراجعة سؤالًا بسؤال.
- **مراجعتي** — الأخطاء، والمستحقّ اليوم (تكرار متباعد)، والأسئلة المعلَّمة.
- **البنك** — بحث بالعربية أو الإنجليزية مع فلترة بالقسم.
- **المرشد** — تقدير الجاهزية، ترتيب الأقسام، خطة أربعة أسابيع، ونسخة احتياطية من التقدّم.

## التشغيل

افتح [mijhar-mlt.html](mijhar-mlt.html) في أي متصفّح. لا حاجة إلى تثبيت أو خادم.

> يُحفظ التقدّم في `localStorage`، وهو خاصٌّ بالمتصفّح والجهاز.
> استخدم «نسخة احتياطية من تقدّمك» في صفحة المرشد لنقله أو حفظه.

## البناء

الملف النهائي مولَّد؛ **عدِّل المصادر لا الملف النهائي**:

```
src/01-head.html      العنوان والأنماط وهيكل الصفحة
src/bank/b*.js        بنك الأسئلة، ملفٌّ لكل قسم
src/99-app.js.html    منطق التطبيق
```

ثم:

```sh
sh build.sh
```

### صيغة السؤال

```js
Q("CC", "نصّ السؤال بالإنجليزية", "خيار1|خيار2|خيار3|خيار4", 2,
  "الشرح بالإنجليزية.", "سطر عربي مختصر");
```

الوسيط الرابع هو فهرس الإجابة الصحيحة (0–3). رموز الأقسام:
`CC HEM BB MIC PAR MYV IMM UBF HIS MGT`.

التطبيق يخلط ترتيب الخيارات في كل جلسة، وفهارس الإجابات في المصدر
موزّعة بالتساوي على المواضع الأربعة (280 لكل موضع). والبدائل مُعايَرة
طولًا حتى لا يدلّ طول الخيار على صحّته: لا يوجد سؤال واحد تتجاوز فيه
الإجابة الصحيحة أطولَ بديل بأكثر من عشرين حرفًا.

## حدود معروفة

- **لا أسئلة مصوّرة.** الامتحان الحقيقي يعرض صور لطاخات وبلورات وطفيليات؛ عُوّض عنها بأسئلة وصفٍ مورفولوجي.
- الشرح يبرّر الإجابة الصحيحة ولا يشرح سقوط كل بديل.
- المحتوى للمراجعة والتدريب، وليس أسئلةً مسرّبة من الامتحان.
